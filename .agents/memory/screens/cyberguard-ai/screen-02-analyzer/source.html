Teknis: Payload File .APK Ancaman Malware

Meminta target memasang “Surat_Resi_Pengiriman.apk”. File paket aplikasi Android liar di luar Play Store ini berfungsi sebagai Trojan sniffer untuk mencuri SMS OTP dan kredensial perbankan.

Identitas: Pengirim Asing Anomali Pengirim

lightbulb Mengapa Pesan Ini Berbahaya?

Pesan ini meniru gaya bahasa korporasi ekspedisi logistik untuk menciptakan kondisi darurat palsu. Secara arsitektur keamanan, perusahaan logistik legal TIDAK PERNAH mendistribusikan berkas pelacakan resi dalam bentuk arsip installer (.apk).

Segala bentuk pelacakan barang resmi selalu menggunakan format nomor tanda terima (resi) alfanumerik yang diperiksa secara independen melalui peramban web resmi ataupun aplikasi resmi yang diunduh langsung dari Google Play Store / Apple App Store.
